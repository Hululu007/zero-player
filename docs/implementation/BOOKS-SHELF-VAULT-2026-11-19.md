# 网络小说书架：移除/删除与私密书架（2026-11-19）

本轮把书架从“只能加入”补成可维护的集合，并新增一个本地加密的私密书架。外部实现提交为 `d5c1698`；本次接续复查前已建立 `zn/backup-before-shelf-vault-review-20261119` 备份分支。本次独立验证结果见第 7 节；真机指纹流程尚未在设备上执行。

## 1. 书架操作

书架卡片右上“书架操作”菜单按书籍归属给出不同项：

| 菜单项 | 行为 | 备注 |
| --- | --- | --- |
| 书单归属 | 勾选公开或私密书单 | 私密书架内只列私密书单 |
| 清除阅读进度 | 只删进度，保留正文与笔记 | 原有行为 |
| 关注/取消关注 | 更新追更标记 | 原有行为 |
| 移入私密书架 / 移出私密书架 | 按需解锁后迁移 | 见第 3 节 |
| 从书架移除 | 二次确认，可勾选“同时删除离线文件与阅读缓存” | 默认不勾选，保留已下载内容 |
| 删除 | 二次确认，“同时删除缓存与离线文件”默认勾选 | 勾选时连正文、笔记、书签一并删除；取消勾选只删书架记录与阅读数据，保留离线文件 |

“从书架移除”与“删除”的差别被刻意限制在两点：是否保留笔记/书签，以及离线内容的默认处置。两者都会先停止该书的下载任务，再清理书单归属，避免留下指向已移除书籍的书单条目。

## 2. 私密书架的数据与加密

私密书架使用加密键空间保存下列记录；音频及 EPUB/PDF 原文件仍在应用私有目录中，**不加密**，不能视为完整文件保险箱。

| 键 | 内容 | 是否加密 |
| --- | --- | --- |
| `books_vault_config` | 16 字节盐、被包装的数据密钥、指纹包装、提示语、创建时间 | 包装密钥为密文 |
| `books_vault_config:key` | 数据密钥（仅内存） | 不落盘 |
| `books_vault_index` | 私密书籍 id 列表 | 否：锁定时也要靠它把私密书从公开书架过滤掉 |
| `books_vault_data:<逻辑键>` | 书架记录、章节正文与图片、阅读进度、笔记书签、离线清单、聚合章节来源、下载计划、书单归属、本书阅读净化选文 | 是 |
| `books_vault_guard` | 连续失败次数与锁定截止时间 | 否（不含秘密） |

加密参数固定写入配置，读取时不信任外部传入的开销参数：

- 口令派生：Argon2id，19456 KiB 内存、2 次迭代、1 路并行、32 字节输出，16 字节随机盐；派生在独立 isolate 中执行，避免阻塞界面。
- 数据密钥：32 字节安全随机数（DEK）。口令派生的 KEK 只用于包装 DEK，改口令只需重新包装，不必重加密全部数据。
- 包装：AES-256-GCM，AAD 固定为 `books_vault_config:key`。
- 数据：AES-256-GCM，每条 12 字节随机 nonce，AAD 使用逻辑键（如 `books_shelf:<id>`），把密文绑定到它应在的位置，防止把 A 书的密文挪到 B 书。
- 密文格式：`v1:` + base64(nonce ‖ 密文 ‖ 16 字节 tag)，普通浏览可按“读不到”处理；迁移、书单编辑和笔记修改使用严格读取，损坏数据会中止操作并保留原密文。
- 迁移：移入时逐键读出明文、写入加密键空间、删除明文键，并清掉 `books_read_cache:`、`books_mixed_cache:`、`books_image_cache:` 下该书的明文派生缓存（这些缓存可重新拉取，不应在加密空间外留存）；移出时反向执行，并把数据写回公开键空间。

私密书籍不写普通阅读缓存与图片缓存，正文只在解锁状态下解密到内存。

## 3. 解锁与防护

- 口令：正确口令才能解开 DEK；错误口令表现为解密失败，不区分“口令错”和“数据坏”。
- 指纹（Android）：Keystore 中保存一个 AES-GCM 密钥，要求每次使用都做生物识别（`setUserAuthenticationRequired(true)`，API 30+ 使用 `setUserAuthenticationParameters(0, AUTH_BIOMETRIC_STRONG)`），并在录入新指纹时失效（`setInvalidatedByBiometricEnrollment(true)`）。系统 `BiometricPrompt`（API 28+）通过 `CryptoObject` 授权该密钥，一次认证只解开一次 DEK 包装。API 26–27 无该提示框，只能用口令。
- 提示框走系统原生界面，不额外引入 Maven 依赖；指纹变更后返回 `invalidated`，Dart 侧提示用口令解锁并重新启用。
- 自动锁定：解锁后闲置 30 分钟自动上锁；应用退到后台立即上锁，包括详情、阅读、下载目标选择以及后台听书；私密听书停止并清除展示元数据。已打开的私密页面在恢复绘制时显示验证入口，私密弹窗关闭。
- 失败退避：连续 5 次失败后按 30/60/120/240/300 秒递增等待，期间不校验口令。
- 忘记口令不可恢复：没有云端副本，也没有后门；设置界面明确提示“忘记口令将无法恢复私密书架内容”。

## 4. 下载到指定空间

详情页的下载弹窗提供“保存到”分段选择；下载管理沿用既有计划的空间，继续下载不重新分配书单：

- 公开空间：可选公开书单；未指定时保留原归属，选择书单或集合时添加归属，选择分组时只替换原分组。
- 私密空间：切换时先验证并立即加载现有私密书单；确认后把书籍迁入私密键空间、从公开书单移除、写入私密书单归属，再按计划下载。
- 私密书籍的下载计划、章节清单与失败记录都写在加密键空间；书架锁定时下载协调器暂停这些任务，解锁后可手动继续，已成功保存的章节会重新核对并跳过。

## 6. 边界与未验证项

- 私密书架是“本地加密 + 应用内访问控制”，不承诺抵抗已 root 设备的内存取证或调试器注入；数据库文件本身仍可被看到，上述数据库记录及离线文字/图片是密文，音频和 EPUB/PDF 原文件不是。密码提示、书籍编号、文件路径等仍可能暴露存在性；不保证系统截图、备份或历史数据库页取证安全。`books_vault_index` 以明文保存私密书籍 id，是为了在锁定时也能把这些书从公开书架过滤掉；由此可推断私密书数量与来源侧 id，但读不到标题、作者、正文、笔记与书单名。
- 指纹只在有指纹硬件、已录入指纹且设置了锁屏口令的设备上可用，且仅 Android 28+；其余情况回退口令。真机指纹（含指纹变更失效路径）未执行。
- 未实现私密书架的跨设备同步、导入导出与批量迁移；迁移是逐书触发的，大书库首次迁移耗时随书籍数据量增长。
- 口令强度只依赖 Argon2id 参数与本机算力，未做在线爆破防护（应用内退避只防界面层重试）。

## 7. 接续复查与修复

本次以现有源码和失败回归为准，修复了以下确认问题：

- 生命周期：从详情/阅读退后台不锁、闲置锁定后保留旧内容、公开下载管理泄露私密书名、私密听书继续后台播放。统一访问门在锁定时销毁子页面、关闭敏感弹窗；私密下载管理从私密空间单独进入，每次进入空间重新验证。
- 数据完整性：损坏密文迁出时被删除、配置损坏被当作首次设置、迟到认证重新解锁、锁定期间仍提交写入、并发设置互相覆盖。增加严格读取、单次加载与串行认证、会话吊销和提交前检查。
- 事务一致性：索引仅在最外层提交后发布；嵌套事务可读取待提交索引，回滚不污染内存。迁移和读写在事务内重新判断空间；UI 迁移先暂停并等待下载结束。
- 隐私遗漏：聚合来源证明、离线漫画图片、本书阅读净化选文随书加密；迁移清除可重建的明文阅读缓存。解锁时自动检查并修复外部版本遗留的私密书明文记录，已有可认证密文优先，不被陈旧明文副本覆盖；失败则回滚并重新锁定。说明音频和 EPUB/PDF 原文件未加密的真实边界。
- 删除与恢复：先清理离线文件，再删除元数据；保留离线内容时保存独立目录，原书单归属清理与书架记录删除同事务提交。仅移除书架但保留笔记时继续保留私密索引，使笔记仍可恢复。公开与私密下载管理分别可找到保留内容。
- 下载归档：首次选择私密空间即可验证并加载已有书单；不再无条件清空全部归属；收藏状态落盘；立即暂停保留续传计划。
- 结构：按书架操作、离线文字/笔记、图片存储拆分 BookStore，并保留实例方法入口；下载选择弹窗拆成状态类和独立视图方法，减少大函数。
