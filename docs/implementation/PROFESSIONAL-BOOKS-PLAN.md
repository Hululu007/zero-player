# 专业图书独立模块：已确认方案与实施规划

版本：v0.3；日期：2026-11-19（Asia/Shanghai）。状态：保留八组问答、22 项已确认选择，补充用户指定的开源图书库/目录优先级及导航调查顺序，尚未开始本功能编码。项目当前进度仍以 [STATUS.md](STATUS.md) 为唯一入口。

## 1. 目标与固定边界

在当前应用新增与「阅读」并列的「图书」模块，提供发现/搜索、书库、下载任务和书源管理。重点覆盖中文专业与出版图书，兼顾英文技术、学术图书。

主流程：**聚合检索或导入分享文本 → 选择作品版本及文件格式 → 本机原生匿名解析 → 有界分片下载/续传 → 文件校验及 ZIP 解包 → 加入独立书库 → EPUB/PDF 离线阅读与笔记**。

用户明确确定的实现边界：

- 优先参考 [LinkSwift](https://github.com/hmjz100/LinkSwift) 和 [YunX](https://github.com/CYQawa/YunX) 的具体协议及下载实现，逐条抽取匿名路径，使用可审阅的本机原生适配。
- 不内置网页浏览器，不依赖 WebView、DOM 执行环境或网页自动化完成解析与下载。
- 不使用任何用户网盘账号、账号密码、登录 Cookie/JWT 或已有浏览器登录态，不引入账号管理和云盘转存流程。
- 允许程序接收、维护正常公开分享流程产生的游客 Cookie、分享令牌和短期下载地址。游客会话不是账号登录；其作用域、有效期与更新仍须正确处理。
- 全部在本机解析并直连来源/网盘及其受控下载节点，不依赖第三方解析服务、不自建必需业务后端、不引入隐藏的共享账号或代理账号。
- 内置书源优先调查用户补充的 GitHub 图书库、结构化目录及开放图书资源，再处理熊猫搜书和相关导航目标；此前提供的普通书站保留为后续候选。具体名单、格式与网盘匿名能力以逐来源验证结果确定。
- 强制账号、超过游客限制、要求网页验证的候选不能算作匿名下载支持；自动尝试已确认同版本的其他匿名候选，全部失败后列明原因并支持更换链接/重试。
- 保留复制来源链接、系统浏览器查看出处的辅助操作，但这不属于原生取链路径，也不替代免登录下载验收。

“统一”是统一输入、文件列表、口令交互、下载任务和结果；每家网盘仍有独立协议、匿名权限和限制。目标是接入调查范围内所有验证通过的匿名路径，不能以“匿名列目录成功”代替“文件下载成功”，也不因某家平台仅有账号路径就偷偷改用登录方案。

#### 3.4.1 书目宝库：先做目录，再验证领取

- 固定提交 `93cf3ffcf5a2e6814644d1747a101272557d7eac`；`docs/books.json` 与 `docs/all-books.json` 是同一 Git blob，仅导入一份。24,071 条分类书目行中，24,002 行为有效 HTTP(S) 链接，去重后为 11,348 个领取链接，全部指向 `url89.ctfile.com`；另外 69 行为“链接未找到”。这些数量不等于去重作品、版本或可下载图书数量。
- 优先使用 JSON 快照，Markdown 作为结构变化时的核对/兜底资料；不嵌入 GitHub Pages，也不执行仓库同步脚本。按稳定来源链接合并重复分类标签，保留原始标题、作者及来源行。上游缺少 ISBN、版次、译者字段，未知值保持未知；不能仅凭标题/作者确认其他渠道可自动替换。
- 上游解析脚本将语种默认设为 `ZH`，并统一填入 `epub/mobi/azw3`。这些是目录声明，不能作为实际语种或格式验证结果；当前目录也不能证明有 PDF。列目录及取得真实文件后再核验 EPUB/PDF；只有 MOBI/AZW3 的条目标为本版格式不支持，不隐式加入转换功能。
- 本次固定仓库树未发现 LICENSE/COPYING；记录目录采用和分发条件，逐项区分目录与所链接图书的许可，不把整库标注为开放许可图书。能否作为可下载内置书源，以来源核验及诚通匿名实测结果决定。

#### 3.4.2 开放资源目录与 VideLibri 的采用范围

`free-library` 固定提交 `c51d8aca85aaebb2656939fc001b5df095d8a483`，目录项目采用 CC BY 4.0，采用时保留署名、来源及修改说明；链接目标图书的条件另查。其检测脚本把任何 HTTP 响应（包括 4xx/5xx）视为可访问，绿勾仅作服务器响应线索，不用于本项目搜索、文件下载或域名准入验收。

首批开放资源候选优先从其列出的 Open Textbook Library、DOAB、FreeComputerBooks 所链接的官方免费书、书格、中文维基文库中筛选，兼顾 Gutenberg、Standard Ebooks。Internet Archive/Open Library 按具体项目区分公开文件、仅目录与需借阅项目，只将实际可匿名取得 EPUB/PDF 的项目纳入领取能力。候选仍按中文专业内容优先排序；公版文学资源用于补充，不替代专业图书覆盖。各目标的检索/API/OPDS/导出能力和真实格式尚待逐站验证，不预先宣称全部支持。

#### 3.4.3 熊猫搜书及相关导航的后续处理

本次首页快照可用普通 HTTP 读取并解析，无需执行页面脚本。已提取 377 个有效 HTTP(S) 导航目标，涉及 370 个不同主机；另有 1 条解码后缺少有效 scheme/host，保留为无效记录。该计数是候选目标数，包含非书类、注册/充值入口、工具等，不等于可用书源数；本轮没有逐站下载验证。

对 `goUrl?url=...` 仅本地解码，保留 Base64 中的 `+`，解码后校验 HTTP(S)、域名和重定向目标，再与 `free-library` 及已有来源去重。合并“导航页 → 原始目标 → 目录/详情 → 领取链接”的来源链；导航收录、广告位或新镜像地址不能直接自动启用为默认书源。其 `robots.txt` 本轮返回 HTML 首页，不作为有效 robots 文本或抓取许可证明。

后续按开放图书/官方资源、专业内容、原生检索和匿名文件能力筛选相关目标；Gutenberg 中文页、书格、书栈网、OpenStax 等仅为已发现的候选线索，其中网页文档若没有 EPUB/PDF，不计首版文件领取支持。先验证目标检索、详情及实际文件，再评估相关导航的下一层链接，不无界递归抓站。

此前公开页面抽样：苦瓜书盘含站内 EPUB 下载入口；小力盘样本指向独立下载子站；读书派样本有诚通/迅雷/夸克入口；Anna 当时 robots 排除搜索/下载路径；Z-Library 给定域默认请求重复 307、直连超时。它们保留在导航批次后的参考池，不构成已内置名单或下载验收。

所有候选统一按中文覆盖、书名/作者/ISBN 能力、版本元数据、匿名文件获取率、访问条件和稳定性筛选。OPDS、SRU 或静态 JSON 是可选目录适配方式，按目标实际能力选用；不要求所有来源具备 ISBN，缺少该字段时明确其搜索能力范围，不补造版本证据。

## 4. 用户流程与界面

1. 「图书」进入独立导航，发现/搜索、书库、任务和书源管理保持各自状态。
2. 搜索启用书源，支持书名、作者、ISBN；逐源返回结果和失败原因，不等待最慢来源才展示。按作品聚合，不足以确认版本的结果保留并列。
3. 展开版本，显示已知语种、译者、版次、格式、大小及匿名可用状态；未知信息明确显示未知。用户选定版本、格式；ZIP 内多本书可选择文件。
4. 自动尝试候选。来源元数据与文件不符、仅预览地址、格式错误、账号限制、超游客限制或网页验证均不能默默当作成功。自动切换前复核同版本关系；证据不足要求用户选择，不误下另一译本或版次。
5. 提取码、ZIP 密码、PDF 密码分类型、按链接/文件配对。先自动读取，歧义/缺失/错误时原生表单确认。可原生显示的图片验证码可人工输入；依赖网页运行的验证停止该候选。
6. 完整原文件校验后解包/导入；任务分别显示“文件已下载”“待密码/待选择”“索引中”“已入库可读”。长文索引可后台进行，不阻塞已可渲染文件进入阅读。
7. 打开 EPUB/PDF，保存文件版本关联的进度、书签、摘录与笔记。扫描件无文本层时显示可阅读、无可搜索文字，避免长期空转索引。
8. 已有本地书按需加入新书库，不重建书籍 ID，不自动迁走原记录；用户可本地导入自己已有文件。

失败列表保留每个候选的结构化原因、重试条件和检查时间。全部受限时提供换链接/修改口令/重试；复制链接和系统浏览器查看出处属于辅助，不把“已打开网页”标记成“已下载”。

书源配置支持已审阅的 URL/固定参数、受约束 HTML/JSON 解析、静态目录字段映射、分页与领取链接规则；导入前校验结构、容量和目标域名。声明格式/语种、目录/图书许可与文件实测分别保存；目录去重不等同作品/版本合并。配置更新只更新数据，原生协议能力随应用受控发布，不下载运行 LinkSwift/YunX 脚本或其他远程代码。用户禁用、收藏、编辑及移除选择不被订阅更新覆盖。

游客会话按提供商和实际站点作用域隔离，续链产生的 Cookie/URL 以绑定快照交给对应任务/分片；不能用另一次响应的 Cookie 拼接旧下载地址。会话过期可原生刷新；必要持久化数据作受保护的临时任务状态，不进入普通导出/备份/日志。恢复不得读取浏览器登录态。

## 6. 整文件下载、大文件和后台实现

### 6.1 分片与续传

首版加入有界分片多线程，协议先确认后并发。具体分片数和全局/每主机并发作为实现参数，以平台预算和提供商限制调整，不照抄上游 32 并发。

- 取得稳定文件身份、已知长度及适用的强 ETag/If-Range、可信摘要或等价证明；主动探测服务是否正确支持 Range。只有文件名/大小相同不足以跨链接拼接。
- 每片核对 `206`、Content-Range 的请求起止/总长、实际长度、可用身份与内容编码一致性。拒绝错位、缺失、重叠或变长响应。
- 服务器返回 `200`、不支持 Range、分片被拒或并发触发限流时，取消并等待在途分片，再按已确认文件身份安全退回单流；不能追加完整响应到旧偏移。`416` 单独核对已完成范围和文件长度。
- 有界任务队列、提供商限流和重试退避；尊重 Retry-After。签名 URL/游客 Cookie 失效时协调刷新一次，向相关分片发布新快照并复核身份；旧代次响应不能写回。
- 持久化稳定候选、计划和已确认写入的范围。分片位图不单独证明字节有效，进程恢复时检查范围、长度及校验信息；无法证明安全拼接时重下。
- `.part` 与最终文件隔离，取消关闭句柄并等待写入退出；整文件完整性、真实格式及解析检查通过后才发布完成。HTML 登录/验证页、预览缩略文件与假扩展名不能入库。
- 候选切换默认重新验证身份；不同字节文件即使属于同一版本也不能拼接。同版本切换只能保证版本选择，不代表二进制相同。

### 6.2 512 MiB PDF 与 ZIP

512 MiB 是本机 PDF 能力目标，不覆盖来源/网盘自身游客上限，也不自动提高所有格式的限制。

- 下载流式写盘；PDF 原文件按路径打开，元数据/首屏/目录先可用，文本按页或后台有界索引，搜索显示索引状态、可取消和恢复。不要求 512 MiB 文件完整读入 Dart 内存再逐页处理。
- 4000 页上限与文本存储容量需一起评估；大文件字节数和页数是不同维度，不为达到 512 MiB 目标无条件放宽页数/索引/内容策略。非索引部分的策略约束不能因延迟处理被绕过。
- 首开耗时、峰值内存、滚动/搜索响应、取消和重开以设备/文件样本记录，覆盖 128 MiB 以上、接近 512 MiB、数字版和扫描件。性能阈值在 P0 结合可用基准设备量化，不声称所有低内存设备必然同速。
- EPUB 保持独立解包预算；ZIP 先列目录，校验路径穿越、绝对路径/链接、条目数、单文件/总输出、重复覆盖及解压后容量，流式或有界解包。选择其中 EPUB/PDF，多个图书不自动误合并。
- ZIP 加密按实际支持算法验证，密码缺失/错误原生输入；未支持的加密算法给明确结果，不能把无法解密当坏图书。RAR/7z、MOBI/AZW3 等转换不进入首版。
- 解包文件和原 ZIP 分开记录；清理仅涉及本任务创建的暂存内容，用户已有压缩包或外部文件不被作为缓存删除。归档保留/清理纳入显式文件管理操作。

### 6.3 存储、索引和策略

默认应用托管，可设置指定目录自动保存和手动导出。应用托管文件为可读数据，临时块、索引、封面和归档具有不同生命周期；清缓存不得删除唯一图书原件。跨书单/旧书库引用先检查后删除。

Windows 指定目录处理覆盖竞争与失败恢复；Android 采用受授权的 SAF/文档 URI 和持久目录权限，不能把 `content://` 当普通磁盘路径。权限撤销、磁盘满、同名竞争、索引失败分别报告；必要时保留应用内可读状态及重试导出，不用覆盖用户已有文件来解决冲突。

文件系统与数据库之间采用可恢复的提交协议，下载成功、导入成功、索引完成分开建模。书库不暴露未完成文件为可读图书；索引尚未完成的有效文档允许阅读，但仍遵守现有内容授权规则。导入/打开/导出/保存关键异步边界复核监管、过滤、来源和书架授权，撤销时取消旧任务、拒绝迟到发布；复用当前已修复的持续授权与无覆盖保存边界。

延迟搜索索引不等于延迟必要的内容准入检查。需要全文检查的情形采用有界逐页扫描，检查完成前不发布为可读书目；在性能记录中分别列出准入等待、索引耗时与打开渲染耗时。不得为缩短首屏时间直接跳过既有正文策略。

### 6.4 Android 后台与其他平台

首版实现下载前台服务、必要通知/权限、任务取消/暂停/继续与持久状态；明确原生服务和 Dart 下载用例之间的宿主、重连及任务所有权。由 P0 原型确定可持续运行的 Flutter 后台执行宿主或原生传输边界，不能只添加一条通知就宣称 Dart 任务可后台恢复。

验收切后台、锁屏、Activity 重建、系统回收、通知取消/拒绝、网络变化及再次启动。强制停止/系统限制无法保证进程不被终止，恢复依持久范围和当前匿名取链重新校验。长时后台下载不借用音频播放维持进程。

Windows 使用同一匿名协议和任务恢复语义；正常退出保存状态，启动可续。TV 同步完成基本检索、候选选择、下载控制、原生口令/验证码输入和遥控阅读，不能只用手机页面截图当 TV 验收。

## 7. 专业阅读与书库

- EPUB/PDF 复用现有渲染和阅读记录，新增模块保持独立列表与导航；实际阅读控件不复制成第二套完整实现。
- EPUB 首版补代码、表格、图片、脚注及内部文档跳转；内部链接解析必须约束在当前包，外部链接与内部阅读跳转分开。复杂公式、竖排、字体及 CSS 用真实样本记录支持范围，不将文字可提取等同排版保真。
- PDF 验收目录、缩放、文本搜索、页码/阅读位置、文档密码与大文件；扫描件可阅读，没有文本层时明确不能全文检索，不默认下载 OCR 模型。
- 文件版本绑定的书签、摘录、笔记支持章节/页码回跳和持久化。先复用明确可行的定位语义；版本或文件变化时不静默套用旧位置。
- PDF 坐标高亮、EPUB 稳定锚点/CFI、OCR、RAR/7z、格式转换属于后续阶段，不以“完整专业阅读”字样暗示首版已全部具备。
- 本地旧书按用户选择添加归属，保留文件、Book ID、进度/笔记和原书库引用；显式格式字段和旧路径识别作为回归项。

## 9. 验收矩阵

| 范围 | 必测事实 |
| --- | --- |
| 匿名能力 | 无用户账号/登录 Cookie/共享账号；只用本流程生成的游客会话；无第三方解析请求；不执行网页浏览器/远程脚本 |
| 提供商/书源覆盖 | 逐来源记录时间和实际步骤；首页/目录成功不代表下载通过；调查受限项与已支持项分开 |
| 结构化目录 | 同一 JSON blob 不重复导入；分类重复合并标签，剔除“链接未找到”；目录行数、唯一领取链接数、作品数及已验证文件数分别统计；更新损坏可保留旧快照 |
| 目录字段与来源链 | 默认 ZH、统一格式声明不冒充实测；缺 ISBN/译者/版次不造数据、不自动跨版换候选；仓库提交/原始文件、导航到领取的来源链与目录/图书许可可追溯 |
| 导航准入 | Base64 的 +、无效 URL、重复目标及重定向逐项处理；上游绿勾/HTTP 错误响应不代表检索或下载通过；未经核验的导航目标不自动启用 |
| 版本及候选 | 同名不同版/译者不误合并；候选自动切换只在已确认版本内；二进制不同不复用旧块 |
| 口令和验证 | 多链接多口令、错误码、密码类型、原生图形验证码；网页验证/账号要求能换候选且保留原因 |
| 游客会话 | 作用域/有效期、URL和Cookie绑定、并发刷新、退出/重启恢复，不泄漏到跨域请求或普通日志/备份 |
| 下载完整性 | 有界分片、错/缺 Range、200/416、压缩传输、尾片、限流、URL换版、磁盘满、取消/崩溃不产假完成 |
| 文件与ZIP | 真实EPUB/PDF、HTML伪文件/预览文件、错密码/算法、穿越/链接/重复项/超限、多个图书选择 |
| 大PDF/索引 | 数字版与扫描版、128 MiB以上至接近512 MiB、首屏/内存/取消、延迟索引/搜索状态及内容策略 |
| 书库和保存 | 旧书ID/进度/笔记、重复引用、格式分类、托管/SAF/导出、权限撤销、同名竞争不覆盖、清理不删原件 |
| 阅读/笔记 | 图文/代码/表格/脚注/内部跳转、PDF目录/缩放/搜索/位置、扫描件无OCR提示、版本绑定笔记回跳 |
| 策略边界 | 来源/监管/过滤/私密锁定变化，在取链、写盘、入库、索引、打开、导出前后复核，不让迟到结果绕过 |
| Android后台 | 锁屏、切后台、Activity重建、系统回收、通知操作/权限、断网/切网和启动恢复，明确强制停止限制 |
