# v0.8.0 阶段预发行

应用版本 `0.8.0+80`，汇总 v0.7.4 之后的性能、阅读、书架和媒体可靠性改进。提供 Windows x64 安装器、便携包与 Android ARM64 开发测试 APK，附源码、第三方声明、原生组件来源和 SHA-256 清单。

- 性能：缩小音乐历史读取与元数据通知范围，减少隐藏页面刷新、播放器视频节点重建、下载 pin 查询、缓存容量扫描与重复摘要读取；后台网络请求在持续交互负载下获得有限等待机会。
- 阅读与书架：补齐书架移除/删除、加密私密书架及锁定生命周期；改进章节下载恢复、聚合最新目录、逐渠道更新检测、本地 EPUB/PDF 格式识别和系统字体选择。
- 来源：更新已核查的新域书源、影视与直播目录；新增 GitHub 渠道文件更新入口，保留用户启停、收藏及移除选择。洛雪TV与看看鸭按既有约定默认收藏。
- 可靠性：修复 12 项审计问题，涵盖最终保存授权、无覆盖导出、可取消探测、HLS/MP4 资源完整性、漫画存储容量及损坏修复、听书排队续播、离线音乐和音频协调。
- 专业图书独立模块的调研规划随源码保存，尚未实现，不属于本版新增功能。

Android 使用独立包名 `dev.zeroplayer.zero_player.devtest` 和已有测试证书，不能覆盖正式 Android 应用。Windows 安装器没有商业 Authenticode 签名。测试包不包含私有签名材料或用户数据库。

本机发布验证及历史功能证据见 [实施状态](STATUS.md)。Android/TV 真机、系统保存与后台生命周期、长期播放、真实媒体/来源可用性仍需设备验收；洛雪TV实时 API 直连超时、看看鸭人机验证等限制仍存在。既有源码规模债务不因阶段发布视为解决。保留 v0.0.11 Windows 稳定发行和既有正式 Android 发行。
