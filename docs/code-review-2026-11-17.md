## 核查结论

原报告计入缺陷的 **77 项**现调整为：**30 项确认并修复（P2 12 项、P3 18 项）**、**46 项撤销或证据不足**、**1 项既有工程债务 F-1**。F-2、J-1 原为说明/观察，单独保留说明，不计入 77 项。

原报告存在三类主要失实：忽略下游已有校验或调用前提；把明确的产品设计当成缺陷；用条件推测推出「永久泄漏」「无限占用」「所有历史失效」等后果。本轮按真实触发条件收窄影响，未照建议更改监管、成人过滤、网络访问或恢复码边界。

以下 P2 表示当前可达的数据一致性、功能或资源生命周期问题；P3 表示提示、边界恢复或局部实现问题。级别描述的是修复前问题，标为修复不表示已做实机或实网验收。本轮没有证实 P1，也不能据此断言所有入口均不存在策略绕过。
